# CamsBoard — Розумна система відеоспостереження з ШІ-аналітикою

**CamsBoard** — це відкрита (self-hosted) система відеоспостереження, запису архіву та інтелектуальної аналітики подій у реальному часі.

Система побудована на базі високоефективної двоетапної архітектури: камери передають (push) **RTMP**-потоки на сервер, **FFmpeg** у реальному часі аналізує їх на наявність змін у кадрі, і лише при фіксації руху передає кадри до Python-сервісу нейромережі **YOLOv8** (через Unix Domain Socket) для точного розпізнавання людей.

---

## Основні можливості

- **Двоетапна ШІ-аналітика (FFmpeg + YOLOv8):**
  - Суттєва економія ресурсів CPU завдяки запуску нейромережі лише при фактичній зміні сцени.
  - Гнучке налаштування чутливості для кожної камери: FPS, поріг зміни сцени (`sceneThreshold`), обробка лише ключових кадрів (`onlyKeyFrames`).
  - Автоматичне виділення людей на кадрах подій та збереження метаданих розпізнавання в БД.

- **Розумне керування відеоархівом:**
  - Автоматичне збереження відеофрагментів навколо моменту тривоги (з урахуванням буфера до початку руху).
  - Багаторівневе автоматичне очищення диска (`Cleaner`): тимчасові сегменти видаляються через кілька хвилин, події без виявлення людини — через 24 години, а підтверджені події з людьми зберігаються до 30 днів.

- **Повноцінна інтеграція з Telegram та Viber:**
  - Миттєві тривожні сповіщення: фотографія з виділеною людиною у Telegram та оперативні текстові повідомлення у Viber із назвою камери, адресою та деталями події.
  - Проста прив'язка акаунта користувача до бота за персональним токеном та вибір мови сповіщень прямо в чаті месенджера.

- **Автоматизація конфігурації та самовідновлення:**
  - Керування камерами через вебінтерфейс автоматично оновлює конфігурацію `mediamtx.yml` та перезапускає відповідні служби `systemd` (`camsboard_device-@.service`).
  - Вбудований моніторинг активності потоків (`heartbeat` через `/tmp/alive-*`) для контролю стабільності роботи кожної камери.

- **Сучасна безпека та багатомовність:**
  - Безпарольний вхід із двофакторною автентифікацією (2FA) через одноразові коди у **Telegram, Viber або Email**.
  - Захист форм входу через **Google reCAPTCHA Enterprise** з динамічною оцінкою ризику.
  - Повна підтримка багатомовності з динамічним завантаженням словників та детальним системним логуванням.

## Архітектура системи

```text
[RTMP Cameras] (Push streams to server)
      │
      ▼
[MediaMTX] (RTMP Server & HLS Streamer)
      │                     │
      │                     ▼
      │            (MP4 video segments) ──► [Disk Storage / Video Archive]
      ▼
[FFmpeg] (Scene change filter + frame segmentation)
  │   │
  │   ▼
  │  [PHP Worker (FFmpegScene.php)]
  │   │
  ▼   ▼
[PHP Worker (FFmpegStdout.php)]
            │ (on scene change)
            ▼
  [Python YOLOv8 Daemon] (Unix Socket /tmp/yolo.sock)
            │ (human detected)
            ▼
  [MySQL DB + Telegram / Viber Notifications]
```

## Технологічний стек

- **Backend:** PHP 8.3+ (модульна архітектура, власний ORM `DataProvider`, REST/JSON API), Python 3.10+ (`ultralytics` YOLOv8, OpenCV).
- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3, HLS.js (відтворення відео в браузері без сторонніх важких фреймворків).
- **Відео та стрімінг:** MediaMTX (RTMP/HLS), FFmpeg.
- **База даних:** MySQL 8.0 / MariaDB.
- **Інфраструктура:** Ubuntu / Apache, `systemd`.
